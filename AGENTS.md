# This registry has moved

Read and follow the current authoring guide at
[TheBoredTeam/boring-notch-extensions/AGENTS.md](https://github.com/TheBoredTeam/boring-notch-extensions/blob/main/AGENTS.md).
The starting prompt is [LLM.txt](https://github.com/TheBoredTeam/boring-notch-extensions/blob/main/LLM.txt).

New Store records and release updates belong in the canonical repository as
`extensions/<manifest-id>.toml`. Do not add new plist listings here or regenerate
this repository's frozen `catalog.plist` as part of a new submission. Historical
sources/tooling and the compatibility feed are retained for existing preview
clients. Do not re-enable automatic publication during unrelated work.

For current ABI signatures, ownership rules, native activities, compact tabs,
signing, packaging, and payment boundaries, use that repository's guide and
[API reference](https://github.com/TheBoredTeam/boring-notch-extensions/blob/main/docs/README.md).
